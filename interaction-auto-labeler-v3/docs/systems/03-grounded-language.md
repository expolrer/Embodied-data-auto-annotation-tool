# S3 实体约束的分层语言系统

## 目标与边界

为每段数据生成适合 VLA 训练的 task、subtask、event 三级自然语言，并把每个名词短语绑定到
事件图中的实体和帧区间。系统负责“怎么准确描述”，不允许 VLM 凭常识补写未观测结果。

## 输入与输出

必需输入：原始任务指令、S1 实体/轨迹、S2 事件与阶段。

增强输入：关键帧 RGB-D、机器人状态、场景 inventory、人工词典和领域本体。

输出包括：

- task：整段任务意图和约束。
- subtask：有顺序的操作步骤、活动手、源区域和目标区域。
- event：与具体实体和时间段绑定的细粒度动作描述。
- referring expression、前置/后置状态、否定事实、来源模型和审核状态。

## 生成链路

1. 从事件图生成结构化事实表，限制可使用的实体、属性、动作、手臂和时间关系。
2. 对确定性高的样本优先使用模板渲染，保持术语、时态和粒度一致。
3. 只在同类实例歧义、复杂关系或失败原因需要解释时调用 VLM。
4. 对 VLM 输出做 entity ID、event ID、时间区间和前后状态的程序化校验。
5. 生成多种表达时保留规范化语义帧，避免语言增强悄悄改变动作目标或左右方向。

## 人工交互

审核页面并排显示语言、实体高亮和对应阶段关键帧。用户修改“右侧红色玩具”为“最右侧红色
毛绒玩具”时，修改必须仍绑定同一个 `entity_id`；删除实体后所有引用应被阻止或重新确认。

## 对 VLA 的使用

- π0.5/语言条件 VLA：task 指令作为原生输入，subtask/event 描述可用于层级条件、数据检索和 curriculum。
- ACT：传统 ACT 可不使用 prompt；语言可作为数据过滤/任务 ID，或在独立实验中通过 text encoder
  与视觉 token 融合。必须与无 prompt 基线配对比较。
- 可训练实体-文本 grounding 辅助损失，但不得把人工语言中的结果泄漏到动作发生前的输入。

## 验收

优先评价实体 grounding 准确率、动作/手臂/方位一致性、时间蕴含、幻觉率、人工编辑距离和
每段审核时间。BLEU/ROUGE 只能反映表面相似，不能替代事实正确性。

当前模板与兼容 VLM 的生成接口已实现，成熟度为 Beta；上线前需要建立领域词典和至少一套
由机器人任务专家审核的语言金标集。
