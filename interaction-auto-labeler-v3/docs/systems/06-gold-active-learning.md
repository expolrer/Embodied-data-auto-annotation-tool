# S6 金标集与主动学习闭环系统

## 目标与边界

把有限人工预算投向最有价值的样本，建立可复现的金标、裁决、校准和纠错蒸馏闭环。系统不负责
直接检测物体，而是决定“哪些机器标签可信、哪些需要人、人的修改如何变成下一版模型”。

## 数据集合约

至少维护四个互不混淆的集合：

- `train_corrections`：可持续加入训练的人工纠错。
- `calibration_gold`：拟合置信度与自动接收阈值。
- `validation_gold`：选择模型与超参数。
- `untouched_test_gold`：冻结，只有正式发布评估时使用。

抽样按任务、场景、日期、相机、活动手、目标类别、同类实例数、遮挡和模型置信度分层；不能只
抽高分或随机容易样本。

## 处理链路

1. 汇总 S1/S2/S5 的不确定度、模型分歧、跟踪漂移、异常和数据新颖度。
2. 结合任务价值、覆盖缺口和预计审核成本计算队列优先级。
3. 普通样本单人审核，高风险/金标样本双人独立审核；不一致进入第三方裁决。
4. 保存追加式 correction、审核耗时、工具版本和覆盖原因。
5. 用金标拟合 isotonic/temperature 校准，发布 precision-coverage 与 risk-coverage。
6. 将纠错导出为检测、分割、边界、语言或质量领域小模型的蒸馏数据。

## 人工交互

页面以一次交互为最小审核单元，并允许跳到风险帧。框/mask 修改、实体重选、边界拖动、语言修改
和成败裁决使用不同结构化操作，不能只保留一段自由文本建议。

## 反馈闭环

每次模型升级先在冻结金标上比较，再灰度处理新数据。只有 calibration set 可用于调阈值；test
set 不能反复查看后继续调参。纠错蒸馏模型必须记录其训练 correction 版本，防止评测泄漏。

## 验收

核心指标为标注者一致性、裁决率、ECE/Brier、目标 precision 下的 coverage、单位审核小时新增的
正确标签数，以及下一轮模型在 untouched gold 上的净提升。人工速度提高但一致性下降不算成功。

当前已有确定性分层抽样、isotonic 校准、队列和纠错导出，成熟度为 Alpha；双人盲审、裁决工作流
和审核成本优化仍需在互动页面中补齐。
