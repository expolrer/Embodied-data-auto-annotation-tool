# S2 交互事件与时序边界系统

## 目标与边界

把连续机器人视频划分为 task、subtask、event 三级片段，并为操作事件标出 approach、contact、
grasp、transport、place、release 等阶段。系统回答“何时发生什么交互”，不重复保存视觉 mask。

## 输入与输出

必需输入：统一时间轴、关节/末端/夹爪或动作状态，以及 S1 的目标轨迹。

增强输入：RGB 场景变化、深度接触、指令、力/触觉、机器人控制模式。

输出包括：

- 带父子关系的 task/subtask/event/phase `Segment`。
- grasp、move、place、release 等 `InteractionEvent` 及 active arm、source、target、destination。
- 边界置信度和 `boundary_uncertainty_frames`，而不是伪装成单帧绝对真值。
- 每个边界的视觉变化、运动导数、夹爪、深度/接触等证据。

## 处理链路

1. 对 RGB embedding 变化、光流、关节速度、末端速度、夹爪状态和深度距离构造同步特征。
2. 用规则产生高召回边界候选，例如夹爪闭合、共同运动开始、目标静止于目的区域。
3. 用多模态时序模型对候选上下文重打分，并联合预测阶段与活动手臂。
4. 通过层级约束解码：event 必须在 subtask 内，subtask 必须在 task 内，阶段顺序受任务类型约束。
5. 将高不确定或多峰边界交给审核，允许审核一个区间而不是强迫选择唯一帧。

场景切换只是一种边界证据。相机抖动、遮挡和曝光突变不能直接等价于任务阶段切换。

## 人工交互

审核界面同时展示头部 RGB、执行腕部 RGB、夹爪曲线、关节/末端速度和目标深度。用户拖动边界
或选择阶段后，系统自动保持三级层级合法，并记录修改前后的误差。

## 对 VLA 的使用

- 按阶段平衡采样，避免长时间 approach 淹没短暂 contact/release。
- 训练 progress/phase 辅助头，帮助模型区分“尚未抓住”和“已经在搬运”。
- 生成 action chunk 的合法起止点，并按事件级划分 train/test，避免同一次动作泄漏到不同 split。
- 阶段标签来自未来信息时仅作监督，部署时由观测在线预测。

## 验收

报告容差窗口边界 F1（例如 ±3/±5/±10 帧）、平均绝对边界误差、segment mIoU、阶段 macro F1、
活动手准确率和人工修订量。学习型边界模型必须在不同任务、不同采集日期和不同机器人上分层评估。

当前保守规则和时序 refiner 接口已实现，成熟度为 Beta；没有金标训练时应明确标记为 proposal，
不能把规则边界当作最终真值。
